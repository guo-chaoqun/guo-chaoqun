# 04 · 术语人话对照表（穿搭评测体系专用）

> 素材来源：`evaluation/workbook/人话对照表.md` 精炼
> 数字口径仅适用于**穿搭项目**，与客服 RAG 项目数字互不混用

---

## 一、系统部件：这套东西是什么

| 术语 | 人话 | 穿搭项目里对应 |
| --- | --- | --- |
| 评测体系 | 给 AI 产品打分的考试系统 | 考卷＋阅卷＋成绩单＋及格线 |
| 考卷 / Golden Set | 一套固定题目，答错能复现 | 50 条用户怎么提问的题 |
| A/B/C 类考卷 | 提要求 / 提禁忌 / 乱来的题 | "韩系温柔点"／"别给白鞋"／空白·注入·矛盾 |
| 判分器 | 代码写的自动阅卷老师（客观题） | 检查方案有没有踩用户禁忌 |
| 裁判 Judge | 另一个 AI 当阅卷老师（主观题） | 评推荐语有没有回应用户要求 |
| harness | 整套考试机器 | 出题→收卷→阅卷→出分的脚本 |
| 跑批 | 一次考试 | 调 50 次产品收回答卷 |
| 冒烟 | 模拟考 | 先考 6 条，花几分钱验证链路（≈0.07 元） |
| 冻结基线 | 把成绩单存档，以后只跟它比 | `l1-baseline-v0.1.json` |
| 门禁 | 退步就拦住不让发布 | `--check` 非零退出码 |

## 二、判分语言：阅卷怎么打分

| 术语 | 人话 | 例子 |
| --- | --- | --- |
| 确判违规 | 确实踩线，客观错 | 说不要黑色，出现黑色高领毛衣 |
| 疑似违规 | 拿不准，挂起等人看 | "月白色"鞋算不算"白鞋" |
| 硬门 | 一票否决红线 | 踩禁忌＝不合格，分再高也没用 |
| 观测线 | 只看不管的参考线 | 兜住率不到 90% 只警告 |
| 阈值 | 及格线 | 七维审美均分 ≥4.0 算过 |
| 到手率 | 真正答上来的比例 | 50 题答出 42＝84% |
| 裁判预判 | AI 老师先打的分（偏乐观） | 0.72＝它认为答对七成 |
| H1–H4 | 四条硬伤 | 温度矛盾/件数超限/露肤越界等 |
| dispute | 判不准，不许硬判 | 风格像不像韩系拿不准时挂争议 |

## 三、统计语言：这个分数有多可信

| 术语 | 人话 | 穿搭项目数字 |
| --- | --- | --- |
| CI 置信区间 | 分数的把握范围 | 到手率 84% [71.5%, 91.7%] |
| Wilson | 算"对错题"把握范围的工具 | 比例类指标用 |
| bootstrap | 算"打分题"把握范围的工具 | A 裁判 0.72 [0.567, 0.867] |
| k 次采样 | 同一题考三次看稳不稳 | B-031 一次 2 色一次 3 色 |
| SRCC | 自动分和人分排不排得齐 | L4 目标 ≥0.5 才采信自动分 |
| κ（Kappa） | 两个阅卷老师口径一不一致 | ≥0.80 可用，≥0.85 放量 |
| MOS | 多人打的平均分（金标准） | L3 审美终审依据 |
| pass^k | k 次全部通过才算可靠 | 约束遵从率的正确测法 |

## 四、流程语言：考试怎么组织

| 术语 | 人话 |
| --- | --- |
| dry-run | 空转机器不花钱，确认没坏 |
| 三段式 | 空转→模拟考→正式考，每段过了才下一段 |
| 归因 | 考砸了分析砸在哪（产品错 vs 阅卷老师错） |
| BadCase 寄存器 | 错题本，五分类、带证据可回溯 |
| 仲裁 | 阅卷拿不准的题，产品负责人拍板 |
| 校准 | 阅卷老师上岗前先试判，确认分得清好坏 |
| 三探针 | 位置偏置 / 量表遵从 / 裕度分辨力 三项体检 |
| 复评口径 | 同一把尺子重打历史分，防止工具偷变 |

## 五、层名速查（L0–L8）

| 层 | 一句话 |
| --- | --- |
| L0 | 先定及格线（目标/边界/阈值/频率） |
| L1 | 产品听不听得懂人话（A/B/C 三类） |
| L2 | 推荐语回没回应要求（七维） |
| L3 | 搭配好不好看（审美七维＋硬伤） |
| L4 | 生成图行不行（对齐/保真/美学） |
| L5 | 错题归因（BadCase 五分类） |
| L7 | 出成绩单（评测报告模板） |
| L8 | 横切：成本/性能/线上信号 |
