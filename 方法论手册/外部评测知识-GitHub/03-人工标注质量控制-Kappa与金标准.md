# 03 · 人工标注质量控制：Kappa 与金标准建设

> 来源：Cohen (1960) κ 系数原始方法、《Analyzing Dataset Annotation Quality Management in the Wild》、Cochrane Handbook §4.6.6（κ≥0.80 阈值）、ViClaim 等金标准构建实践（2024–2026）
> 学习目标：能讲清"怎么证明两个标注员的分可以互认"，以及金标准集从 0 怎么建
> 与项目映射：穿搭 D3 人工 MOS 金标准集（待建）、SOP 里的 Kappa 门禁 0.80/0.85

---

## 一、为什么不能用"一致率百分比"

两个标注员 100 条里意见相同 90 条，一致率 90%，听起来很高——但如果任务本身 90% 的样本都明显是"好"，而两人也都按 90% 好 / 10% 差的比例随机打标，那么**纯靠蒙的期望一致率** Pₑ = 0.9²+0.1² = **0.82**。此时即便观察一致率 Pₒ=0.90，κ=(0.90−0.82)/(1−0.82) 也只有 **0.44**（中等偏下）。**百分比一致率不扣除"蒙对"的部分，这就是 κ 要解决的问题。**

**Kappa（κ）= 扣除随机一致后的一致性**，取值 [−1, 1]：

- κ < 0：比瞎蒙还不一致；
- κ = 0：等于随机水平的一致；
- κ > 0：超出随机的真实一致。

经验门槛（多行业通行，Cochrane 手册采用 0.80）：

| κ 区间 | 含义 | 行动 |
| --- | --- | --- |
| < 0.60 | 不可用 | 标准有问题，返工 |
| 0.60–0.80 | 中高度一致 | 限定用途、继续磨锚点 |
| **≥ 0.80** | 标准可投入使用 | 正式开标注 |
| **≥ 0.85** | 几乎完美 | 可以放量 |

> 我的 SOP 口径：2 人用 **Cohen's κ**，3 人及以上用 **Fleiss' κ**；0.80 可用、0.85 放量。这是行业标准口径，不是自造。
> 注意 κ 的前提：同样的标注员标完全部样本、不能有缺失项；当某一类样本极小（如分割图里病灶占比极小）时 κ 会失真，需要配合 heatmap/IoU 等辅助指标——**知道边界比会算更重要**。

## 二、金标准（Gold Standard）怎么建

行业数据集论文（如 ViClaim）的典型流程：

1. **双人协作起草**：两名熟悉业务的人先共同标一小批（如每种场景 5 条 × 场景数），逐条讨论达成一致，形成**初代金标**——金标不是一个人拍出来的；
2. **写进指南**：把讨论中产生的判定规则、边界裁定回写标注指南（rubric 锚点 + 正反例）；
3. **持续追踪**：正式标注期，让标注员的产出**持续与金标比对**，发现偏离立即介入、再培训；
4. **争议仲裁**：分歧样本走仲裁人终裁，裁定结论回写标准、版本号 +1；
5. **金标自身也要版本化**：标准升级后旧金标需复审，历史数据按同口径处理。

## 三、试标校准批次（Pilot）完整动作

这是从"标准写好了"到"敢放量"之间的必经一步：

```
2+ 名标注员，独立、互不通气，用初稿各标同一批 20–30 条
            ↓
       算 Cohen's / Fleiss' κ
            ↓
  ≥0.80 → 锁定标准，放量；<0.80 → 逐条看分歧
            ↓
 分歧归因：是标准写得糊（改锚点/补正反例），还是人没培训（再培训）
            ↓
 原则：先怀疑标准，不先怀疑人 → 改完再跑一轮 pilot
```

双盲协议（Dual-Human Labeling Protocol）还要求：标注双方对彼此**盲**，预先注册"κ≥0.80 才算通过"这一门槛——**门槛在标之前就定好**，不能标完看结果再改阈值。

## 三·补、MOS 实验具体怎么操作（主观分金标准的打法）

> Kappa 管"类别标签一致性"，MOS 管"主观打分的可信度"，两者配合。穿搭 D3 要做的就是这件事。

**MOS（Mean Opinion Score，平均主观分）标准流程：**

1. **样本与评委**：34 套搭配（场景×风格矩阵每格抽样），3 名左右评委（最低 2 人，1 人只能算自一致性）；
2. **独立双轮盲评**：样本随机乱序，评委之间互不通气；隔 ≥7 天用新乱序再打一轮——既测评委间一致性（κ/ICC），也测个人稳定性；
3. **打分口径**：每套按 SOP 七维各打 1/3/5，硬伤 H1–H4 先做一票否决，判不准标 dispute，不许硬给分；
4. **聚合**：单套单维分 = 各评委分的平均；**报告带离散度（标准差或评委间极差）**，分歧大的样本自动进仲裁，不能只报一个平均分掩盖分歧；
5. **两道验收**：①评委间 κ（分类）/ICC（连续分）≥0.80 才可用；②机器分与 MOS 的 Spearman ρ≥0.5，自动评分才可采信、否则只做初筛。

> 一句话链路：**SOP 定尺子 → 多人独立盲打 → κ/ICC 验尺子可信 → 平均分成 MOS 金标 → 机器分对 MOS 算 ρ 决定能否采信。**
> κ 与 Spearman 的具体公式见 `../../statistical-significance-tests-methodology.md` 第五·补节。

## 四、标注质量的日常控制手段

- **金题插入**：标注任务流中随机插入已有标准答案的"金标题"，实时监控个人准确率；
- **重叠标注**：按比例（如 10–20%）让两人重复标同一批，滚动算 κ，监控标准漂移；
- **随机化与限量**：样本顺序随机、单批量受限，对抗顺序疲劳；
- **分歧队列**：所有不一致进仲裁队列，仲裁产出回灌标准；
- **反馈闭环**：定期向标注员同步个人 κ 与典型错例。

## 五、映射到我的项目（D3 落地清单）

穿搭 MOS 金标准集要补的动作，按本节对齐：

1. 七维 SOP v1.0 已定（打分卡 + H1–H4 + 锚点）——指南初稿就绪；
2. 待办：双人各标同一批（场景×风格矩阵每格抽样），算 κ；
3. 诚实红线：**只有我一个人时隔 3 天盲评两轮，只能报自一致性（self-agreement），不得写成标注员间一致性**；
4. 金标成型后：纯审美维度以 MOS 为终审，VLM 分仅在与 MOS 的 Spearman 达标后作初筛；
5. 金标题插入 + 10–20% 重叠标注，作为后续扩量时的质控设计。
