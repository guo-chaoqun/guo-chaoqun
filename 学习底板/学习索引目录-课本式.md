# 大模型评测 · 学习索引目录（课本式）

> 建立：2026-10-15 ｜ 定位：像课本目录一样，把全部方法论按**能力递进**织成"章 → 小节"
> 规则：本文件只做映射，不移动任何原文档；每个小节都能点击直达
> 覆盖方向：大模型评测 / 模型质量 / 数据标注质检 / AI 训练师
> 用法：**第一次学按章顺序走（第 1→9 章）；复习/卡壳时按小节查**

---

## 全书能力主线（为什么章节是这个顺序）

```
第1章 建立全局观（评测是什么、长什么样）
  → 第2-4章 评测四件套：定标准 → 出考卷 → 配阅卷（核心能力）
    → 第5章 特定系统专题：Agent 轨迹 / RAG（把核心能力用到具体系统）
      → 第6章 证明可信：统计检验（你说"变好了"凭什么）
        → 第7章 形成闭环：失败归因与迭代
          → 第8章 规模化：工具与工程化
            → 第9章 综合实战：两个项目从头串到尾
（附录：PM 方向旧章，当前选修）
```

一句话：**认知 → 造构件 → 用在具体系统 → 证明可信 → 闭环 → 工程化 → 综合实战。**

## 三种读法（按你所处阶段选）

1. **系统首学**：第 1 章 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9，逐章递进，每章做完自测再下一章；
2. **定向读法**：偏 Agent/标注方向走 1→2→3→**5.1**→6→9.1；偏 RAG/客服评测方向走 1→2→3→4→**5.2**→6→7→9.1→9.2；
3. **卡壳查词**：直接跳到对应小节，不按顺序（教材当词典用）。
