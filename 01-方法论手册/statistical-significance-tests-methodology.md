## 一、选型决策树（30 秒选定）

1. **配对吗？** 同一批题跑两版=配对（评测里 90%）；两批不同对象=独立。
2. **数据类型？** 只有对错=二元；打分数=连续。
3. **样本/分布？** 小样本或不正态→精确检验或 bootstrap。

```
配对 + 二元对错  → McNemar（b+c<25 精确二项版；≥25 卡方连续校正版）
配对 + 连续分数  → 配对 t；不正态 → Wilcoxon 符号秩 / 配对 bootstrap
独立 + 二元      → 两比例 z / 卡方
独立 + 连续      → 独立样本 t
两变量关系       → Pearson（连续线性）/ Spearman（排名）/ 点二列（连续×二元）
不想做分布假设   → bootstrap（业界主推，≥5000 次重采样）
```

行业口径（2026 论文与评测库共识）：二元配对指标 McNemar，不一致对 n<25 用精确二项、n≥25 用连续校正卡方；分级分数用配对 t 或配对 bootstrap；检验同时配差值的 bootstrap 置信区间。

## 二、McNemar（主考项）

### 2.1 原理：只看翻盘题

同一批 N 题两版各考一次：

| | V2 通过 | V2 不通过 |
| --- | --- | --- |
| **V3 通过** | a 两次都对 | b 改对了 |
| **V3 不通过** | c 改坏了 | d 两次都错 |

a/d 无信息量；只有 b、c 能说明改动效果。H₀：改动无效，b 与 c 长期五五开。

### 2.2 公式

**精确二项版（b+c<25）**：把翻盘题当 n=b+c 次抛硬币

$$P(X \geq b)=\sum_{i=b}^{n}\binom{n}{i}(0.5)^n$$

双侧 p＝两尾之和（scipy：`binomtest(min(b,c), b+c, 0.5, alternative='two-sided')`）。

**卡方版（b+c≥25）**：

$$\chi^2=\frac{(|b-c|-1)^2}{b+c}\quad(\text{连续校正}),\quad df=1$$

### 2.3 本项目实算（b=23, c=9, n=32）

| 算法 | 统计量 | p |
| --- | --- | --- |
| **精确二项（采用口径）** | — | **0.0201** |
| 卡方无校正 | 6.125 | 0.0133 |
| 卡方连续校正 | 5.281 | 0.0216 |

三种算法 p 都 <0.05，结论稳健。效应量＝净改善 (b−c)/N = 14/505 = **2.77pp**；配对差 bootstrap 95%CI = **[0.59pp, 4.95pp]（不含 0）**（10000 次重采样演示）。

### 2.4 操作 5 步

1. 保留两版**逐条**判定（只有总分列不出 2×2）；
2. 四格计数；
3. 按 b+c 选精确/卡方；
4. 同时报效应量；
5. 配 bootstrap 差值 CI。

> 隐藏前提：两版必须同一裁判、同一套题（复评基准），否则 2×2 里混着裁判漂移。

## 三、其他四个检验

| 检验 | 公式 | 适用 |
| --- | --- | --- |
| 配对 t | $t=\bar d/(s_d/\sqrt n)$, df=n−1 | 同批题两版分数差，差值近正态 |
| Wilcoxon 符号秩 | 非参数，按差值大小排序看正负 | 分数有封顶、大量并列 |
| 独立样本 t | $t=(\bar x_1-\bar x_2)/\sqrt{s_1^2/n_1+s_2^2/n_2}$ | 两批不同对象（两组标注员、两人群） |
| 卡方独立性 | $\chi^2=\sum(O-E)^2/E$, df=(r−1)(c−1) | 版本×错误类型分布；每格 E≥5，否则 Fisher 精确 |
| 相关显著性 | $t=r\sqrt{(n-2)/(1-r^2)}$, df=n−2 | r 显著≠因果 |

项目实算：完整性维度分×是否通过，点二列 **r=0.859，n=505，t=37.63，双侧 p≈10⁻¹⁴⁸**。

## 四、置信区间（比 p 值更该报）

报告四件套：**点估计＋区间＋方法＋n**。

**Wilson（比例指标，p 近 0/1 或小样本必须用它，Wald 会越界）**：

$$\frac{\hat p+\frac{z^2}{2n}\pm z\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}}{1+\frac{z^2}{n}}$$

**Bootstrap（非比例：均分/F1/r）**：有放回重采样 5000–10000 次取 2.5/97.5 分位；偏态用 BCa。

穿搭项目实算复核：

| 指标 | 点估计 | 95% CI | n/方法 |
| --- | --- | --- | --- |
| L1 到手率 | 84.0% | [71.5%, 91.7%] | 50, Wilson |
| B 违规 | 0% | **[0%, 35.4%]** | 7, Wilson |
| C 通过 | 100% | [77.2%, 100%] | 13, Wilson |
| A 裁判命中 | 0.72 | [0.567, 0.867] | 15, bootstrap（部分命中非二元） |

CI 第一课：**先问"这指标是不是真二元、分母到底是谁"，再选公式**（a_hit 误用 Wilson、分母 40 误代 13 是本项目真实踩过的两错）。

## 五、四个必须分清的概念

1. **p 值**：H₀ 成立时出现当前/更极端结果的概率。p=0.02≠"改进有 98% 概率为真"。
2. **α**：容忍误报率，惯例 0.05，事前定。
3. **显著≠重要**：样本一大 0.5pp 也显著；必须同时报效应量与 CI。
4. **功效 power**：真有差异时检得出的概率。小样本"不显著"只能说"没检出"，不能说"没差异"（n=7 的"0 违规"即此处境）。

## 五·补、标注一致性的两个算法（Kappa 与 Spearman）

> 这一节补上外部 03 篇"只给门槛没给算法"的断层：标注岗培训和评测二面都可能让你算。

### 5.1 Cohen's κ（两个标注员，分类标签是否一致）

步骤：①N 条样本两人各打标签；②算**观察一致率** Pₒ＝两人相同条数/N；③算**随机期望一致率** Pₑ＝各类占比平方和（两人独立乱打也会撞上的概率）；④代入：

$$\kappa=\frac{P_o-P_e}{1-P_e}$$

分母 1−Pₑ 的含义："扣除运气之后，还剩可提升的空间里，实际一致了多少"。

- 多人（≥3）用 **Fleiss' κ**（同思想，允许多人对每条打分）；
- 连续分数（如 1–5 分）不用 κ，用 **ICC（组内相关系数）**；
- Python：`sklearn.metrics.cohen_kappa_score(labels_a, labels_b)`。

### 5.2 Spearman ρ（自动分与人评的排名是否一致——穿搭 L4 的 SRCC）

场景：裁判/VLM 给一组方案打分，人也打分，要验证机器排名靠不靠谱。
做法：把两组分数各自换成**排名**（第几名），再对排名算 Pearson 相关：

$$\rho = 1-\frac{6\sum d_i^2}{n(n^2-1)}$$

dᵢ＝第 i 条在两组排名里的名次差，n＝样本数。

- 取值 [−1,1]，ρ=1＝排名完全一致；用排名而非原始分，**抗极端值、不要求线性**，适合打分数据；
- 穿搭 L4 采信线 **ρ≥0.5**（行业"较强相关"下限），低于 0.5 自动分只能做初筛；
- Python：`scipy.stats.spearmanr(model_scores, human_scores)`。

### 5.3 κ 与 ρ 的分工（一句话别混）

- **κ**：两个**人**对同一批样本打**类别标签**（违不违规、A/B/C 哪类）一不一致；
- **ρ**：机器分和**人分**这两列**连续打分**的**排名**对不对齐。

## 六、多重比较校正

m 个检验在 α=0.05 下平均 5%m 个假阳性。
- **Bonferroni**：α/m，最简单最保守；
- **Holm**：p 排序逐个比 α/(m−i+1)，少牺牲功效；
- **BH/FDR**：控制显著结果中的假阳比例，套件几十个指标时首选。
