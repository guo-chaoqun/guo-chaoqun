# A 组 · 关键坑（5 个，要能完整讲）

## A1. 第一批方案被否——「先围工地 vs 先打地基」

- **现象**：最初把"建目录树（组织与标准）"排第一批，被导演否掉："不能因为没搭地基，就优先去搭高楼层。"
- **根因**：把"形式准备"误当"逻辑起点"。
- **教训（关键教训）**：**目录是结果不是起点**。先找"什么东西没有它其他都没意义"——本项目是阈值口径（L0）。重排出四句依赖链后，它成了整个体系的骨架。

## A2.「月白」误判——第一轮先修的是阅卷老师，不是产品

- **现象**：判分器见"月白鞋"含"白"字就判违反"白色鞋类"禁令；实际禁令是"颜色＋品类"复合约束（用户禁的是白**鞋**，不是所有白色单品）。
- **修复**：v0.2 色族兜底降级为"疑似"，进"判不了"通道转人评，不硬判；v0.3 复合禁令限定槽位。
- **教训（关键教训）**：自动化判据要留**"疑似"出口**；**从零建体系的第一轮优化对象是阅卷机器（仪器），不是产品**——仪器误报会污染所有后续结论，先校准仪器再考学生。

## A3. 三探针 FAIL——错的可能是探针，不是裁判

- **现象**：L2 裁判第 1 轮校准 FAIL，逐条诊断后发现三个"失败"各有归属：
  1. "第三人称"对照裁判给了 d6=2 精准命中语气维——**我的探针判据一刀切（max≤2），没看维度**；
  2. "隐私注入"放在裁判侧本身是设计错——隐私归规则通道，规则一次就抓到；
  3. 只有"未提及场合给满分"是裁判真缺陷——补三条尺度硬规则后第 3 轮 PASS。
- **教训（可背）**：**仪器 FAIL 先分三类——仪器真坏 / 探针设计错 / 判据过严**。校准不是单向调裁判，是双向对质。

## A4. B-031 跨层互查——两天最大的发现

- **现象**：L2 裁判判某方案四色违反"不超两色"；逐层对质发现 L1 基线同题单次采样是 2 色合规——**同一输入两次调用，一次合规一次违规**。判分器没漏判，是生成结果本身在波动。
- **三条推论**：
  1. 单次采样的遵从率不可外推——"违规 0"的准确含义是"**本次采样**违规 0"；
  2. 约束类必须 k 次采样（同一题考多次取多数，行业标准 3 次）——列为 P0；
  3. L2 裁判证明了独立价值：它抓到了 L1 单次采样看不见的违规。
- **定量印证**：B 类可判样本只有 n=7，"违规 0"的 **95% 置信区间（把握范围）上界是 35.4%**——小样本的零违规几乎什么都证明不了。

## A5. 零方差不是满分证据

- **现象**：L2 d6 语气维 40 对全部 5.0，CI=[5.0,5.0]。
- **教训**：零方差 = **无分辨力**（裁判不敢扣分的信号），该维阈值不可拍；同理 d3 体型维 39/40 被扣 3（判据太宽），只作观测不进阈值——**不分辨的维度如实标注，不硬凑结论**。

# B 组 · 工程知晓（5 个，知道教训即可，不用背代码细节）

## B1. 盘点时的采样偏差
- 一句话现象：只搜 `*.py` 就断言 `rules/` 目录不存在，实际规则文件是 JSON。
- **记住的教训**：断言"没有 X"前先答三问——**哪个范围没有？在哪一层验的？检索方式覆盖目标形态吗？**盘点结论错，整栋楼歪。

## B2. 手写考卷 29 处 JSON 语法错
- 一句话现象：50 条手写考卷，机器校验抓出 29 处同一类括号笔误。
- **记住的教训**：**人写的结构化数据，入库前必有机器闸**；评别人之前先评自己的评测数据。

## B3. 黑色 hue=0.0＝白色 hue=0.0，冒烟侥幸没炸
- 一句话现象：颜色判据把黑和白算成同一个值，6 条小批测试恰好没命中，全量跑必然误判。
- **记住的教训**：**冒烟没红 ≠ 没有 bug**——主动拿边界值（黑、白、空、超长）去试，比等事故自然发生便宜得多。

## B4. hasattr 静默吞掉空回复
- 一句话现象：脚本取错了数据层级（`resp.style_notes` 实际在 `resp.outfit.style_notes`），容错代码没报错、悄悄给了空串，导致 42 条回复全空。
- **记住的教训**：**容错降级用在探路上可以，用在关键产出上就是埋雷**——关键数据落盘必须显式检查非空。

## B5. 置信区间自己算错两处
- 一句话现象：①把"部分命中"的指标当成纯对错题套错公式；②通过率分母用 40，实际有效样本只有 13。
- **记住的教训（CI 第一课）**：算区间前先问两句——**这个指标是不是纯二元（只有对/错）？分母到底是谁？**改完留痕，不悄悄改。
- 顺带知道的数字（A 组也会用到）：到手率 84% **[71.5%, 91.7%]**（n=50）；C 100% **[77.2%, 100%]**（n=13）；A 裁判 0.72 **[0.567, 0.867]**（n=15，区间宽 30pp＝样本太少的证据）。

## 贯穿全程的六条方法论沉淀

1. 先定及格线再跑分（防程序倒置）；
2. 失败例是宝——8 条截断全留原文，成了 BadCase 寄存器首批；
3. 冒烟没红≠没 bug（边界值实证）；
4. 判分器要有"判不了"的自知之明；
5. 口径诚实——开放项不编数、重采样标注"非同批"、不动已冻结基线；
6. harness 保持薄——"一百条手写用例＋六十行 runner，胜过优雅插件架构套八个占位符"，考卷和判分器才是资产。
